# Microsoft app icons

Rootly's 192×192 color icon and 32×32 transparent white outline icon for the
Microsoft 365 app package. They use the Rootly brand mark and purple `#8D6FDE`;
the vector mark is also available in the adjacent `../logo.svg`.

These are the reviewed icons used by the initial Microsoft package. Their exact
SHA-256 values are pinned in `tools/scripts/public_assets.py`. Other binary files
remain prohibited by publication checks. An icon change requires visual review
and an explicit update of those pins; naming a file `color.png` does not exempt
arbitrary bytes from scanning.
